# Changelog

## 0.1.1

- Add a **Warmth** control and make the highlight **diffusion** a warm, milky
  veiling glow — retuned the defaults and presets toward a cosy early-2000s
  broadcast look (the "DVW-790 Studio", "Studio" and "ENG / News" presets).

## 0.1.0

- Initial **Early 2000s Television Broadcast** effect for RapidRAW v1.7.0:
  electronic softness, contour correction, chroma-detail reduction, broadcast
  colour punch, highlight roll-off + diffusion, skin smoothing, optional clean
  video noise / interlacing, optional PAL-SD resample, master Amount, presets.
- Idempotent, hash-safe source-tree installer (`install.mjs` / `uninstall.mjs`)
  with `--dry-run`, manifest/backups, and EN/DE i18n deep-merge.
